# Technology Stack

Ojowacam uses a modern stack, prioritizing performance and rapid development.

| Component | Technology |
| :--- | :--- |
| **Mobile UI** | React Native + TypeScript |
| **Android Camera** | Camera2 / CameraX |
| **iOS Camera** | AVFoundation |
| **Android Encoding** | MediaCodec |
| **iOS Encoding** | VideoToolbox |
| **Video Transport** | WebRTC |
| **Audio Transport** | WebRTC audio track |
| **Desktop Windows** | C# / .NET 10 |
| **Windows Virtual Camera** | Media Foundation virtual camera API |
| **Windows Audio** | WASAPI |
| **Desktop macOS** | Swift / SwiftUI |
| **macOS Virtual Camera** | CoreMediaIO DAL-plugin |
| **macOS Audio** | CoreAudio |
| **Shared Core** | C++ |
| **Build System** | CMake |
| **Protocol** | Protobuf / WebRTC data channels |
| **Local Discovery** | mDNS / DNS-SD |
| **Testing** | Jest, XCTest, xUnit
