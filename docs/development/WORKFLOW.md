# How Ojowacam Works

Ojowacam follows a specific workflow to connect a phone to a computer.

## 1. Discovery & Pairing
- The user opens the Ojowacam app on the phone.
- The phone displays a QR code.
- The user opens the desktop companion.
- The user scans or enters the pairing code.
- The devices authenticate each other.

## 2. Session Negotiation
- Authenticated session establishment.
- WebRTC negotiates video and audio streams.

## 3. Streaming
- Wi-Fi LAN / USB.
- Real-time video/audio transport.

## 4. Decoding
- The desktop client receives and decodes the stream.
- Exposes the phone as a webcam and microphone.
